# 💬 MiniChat
Anonymous real-time chat via MQTT over WebSockets · No backend · No registration
MiniChat is a lightweight web application that allows you to chat in public rooms using only your browser. It requires no server, database, or authentication: everything communicates directly between clients through public MQTT brokers.
>⚠️ Privacy Warning: Messages travel through public MQTT brokers and are not stored. Anyone who knows the room name can join and see the content. Do not share private or sensitive information.
Note: This project was developed by Qwen (Alibaba Group's Tongyi Lab).
## ✨ Features
🆓 No registration or installation – Works directly in the browser.
🔗 Rooms by name – Share the link or room name to chat with anyone.
💬 Text messages – With emoji support, visual grouping, and "typing..." indicators.
👥 Real-time presence – User counter with heartbeats and MQTT Last Will Testament.
🔔 Generative sounds – Notifications using WebAudio (no external files).
🌙 Modern dark theme – Inspired by Discord/Telegram, with smooth animations and an ambient background.
📱 Responsive – Adapted for mobile, tablet, and desktop.
♿ Accessible – Supports prefers-reduced-motion, keyboard navigation, and ARIA labels.
🚀 Zero-backend – Only HTML + CSS + Vanilla JS + mqtt.js.
